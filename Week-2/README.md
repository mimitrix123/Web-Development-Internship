## Project – Interactive Image Gallery
Chosen assignment: **Interactive Image Gallery**.

Features:
- 8-image responsive grid.
- Hover scale/lift animations.
- JavaScript click handling.
- Full-screen lightbox preview.
- Close button, backdrop click and Escape-key support.
- Responsive layout for desktop, tablet and mobile.
- Accessible image alt text and dialog labeling.
