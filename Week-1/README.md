# Web Development Internship — Week 1

## HTML & CSS Fundamentals

Completed from the supplied Week 1 material.

### Practice set
1. HTML page with heading, paragraph and image.
2. Student table with names, roll numbers and marks.
3. Registration form using text/email/password inputs, select, radio buttons, checkbox and submit button.
4. Navigation between three pages using relative links.

### Assignment 1 — Portfolio Webpage
A responsive personal portfolio containing:
- About
- Education
- Skills
- Contact
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Profile image placeholder
- Responsive CSS styling
- Accessible labels and image alt text
